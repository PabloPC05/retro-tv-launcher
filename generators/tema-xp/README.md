# Tema Windows XP / Frutiger Aero del launcher del piso

Misma base que `tema-98` (el parche `../parche-win98/win98.patch` lleva las dos skins): con `glass_style: "xp"`
los mismos elementos toman el aspecto de Windows XP Luna: fichas como ventanas XP (barra azul brillante en la
enfocada), selector de cristal transparente y brillante, barra de tareas azul con botón verde «inicio», bandeja
azul clara, menú Inicio con cabecera azul, iconos de escritorio de XP, botones y casillas de XP, y fondo
Frutiger Aero propio (cielo, colina, burbujas; `make_wallpaper.py`, dibujado en código).

La letra va en el APK: `bldskin.sh xp` compila con Selawik (OFL, parecida a Segoe UI) y `bldskin.sh win98` con
MS Sans Serif. Cambiar de skin = instalar su APK y subir su tema (`config.json`, `wallpaper.jpg`, `banners/`).
Iconos de XP: softwarehistorysociety/XPIcons (Unlicense); bandera: remake GPL-2.0 (ver CREDITOS).
